## 수업 운영 권장안

- 강사는 먼저 예상 결과를 질문한 뒤 코드 셀을 실행합니다.
- 학생은 실행 결과를 확인하고 코드의 한 부분을 바꾸어 다시 실행합니다.
- 각 노트북의 `Checks`를 통과한 뒤 다음 실습으로 이동합니다.
- 종합 프로젝트는 결과 디렉터리, 로그, 체크섬을 함께 제출합니다.

## 실행 환경

- Linux 또는 macOS
- Bash 3.2 이상
- Python 3.10 이상
- JupyterLab 4

Windows 사용자는 WSL2의 Ubuntu 환경에서 실행하는 것을 권장합니다.
